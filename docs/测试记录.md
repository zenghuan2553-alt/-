# v0.1.0 验证记录

日期：2026-10-05。

## 环境

Windows 11 专业版，Intel Core i5-13600KF，约 32 GB 内存，Python 3.12.9。实际使用 CPU int8 模式；未使用显卡加速。

## 结果

| 项目 | 结果与范围 |
| --- | --- |
| 依赖 | 安装包与 PyPI 官方 SHA-256 比对通过，依赖一致性检查通过 |
| 模型 | 按 Hugging Face 官方元数据核对模型大小与 SHA-256，通过 |
| 音频处理 | 声道转换、重采样、静音判断、有界队列、停顿分段和最长片段检查通过 |
| 十条离线样本 | 均生成原文与中文；人工判断九条主要意思可理解，VAE 示例出现关键识别错误 |
| 真实系统输出 | 三段本地合成英文语音通过默认扬声器播放，均捕获并生成中文字幕；停止后正常退出 |
| 字幕界面 | 中文布局检查通过，实际 Windows 控制窗口显示就绪状态 |
| 十五分钟持续检查 | 本地合成音频持续送入识别、翻译和字幕界面，运行 900.2 秒，产生 299 条字幕，无错误 |

持续检查中的每分钟工作集采样约 439.5～518 MB，之后回落；900 秒时约 439.8 MB，停止释放模型后约 222.9 MB。未观察到持续累积的内存增长。

模型加载后，十条短样本的识别加翻译耗时约 0.36～0.41 秒，中位数约 0.375 秒。数据不包含捕获、分段等待及模型加载，不能当作端到端字幕延迟；端到端 P95 尚未测量。

## 已知质量问题

- VAE 示例被识别为“VD coder”，导致关键语义错误。
- program 有时译为“节目”，技术上下文表达不够自然。
- 连续无停顿语音仍可能在六秒上限处被切断。

## 未完成的兼容性验收

不同网站的实际视频播放尚未完成验收。第三方播放器、耳机、S/PDIF、显示器音频、全屏、多显示器、不同 DPI 和设备重接未逐一测试。

十五分钟检查使用合成语音处理管线，不等同于十五分钟网页实播。清晰合成语音结果也不能代表所有口音、噪声和真实教程。

## 已修复问题

- 固定 PyAV 16.1.0，解决最新版音频解码接口与 faster-whisper 的兼容问题。
- 固定三秒切段改为停顿优先分段，减少截断句子造成的误译。
- WASAPI 静音时不送音频包，采用可读帧检查及无包停顿判断，避免等待下一次声音才显示字幕。
- 模型下载增加断点续传与完整性校验，避免使用未下载完整的文件。

测试脚本随源码提供；音频样本由 Windows 自带英文语音本地生成，原始结果由脚本写入本地 JSON，不上传用户音频或字幕。
