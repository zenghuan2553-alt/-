# Windows 全局实时字幕翻译器 MVP：零付费可用版

版本：v1.1  
日期：2026-10-05  
用途：直接作为后续开发任务说明。以本版替代 v1.0 的功能范围。

## 1. 项目目标与优先级

做一个 Windows 桌面工具：用户播放英文视频，点击开始，即可看到悬浮中文字幕。

**不局限 YouTube。凡是 Windows 能正常输出声音的网页或软件，均作为目标音频来源；通过系统音频捕获实现，不依赖网站字幕或浏览器插件。** 受保护音频、特殊输出路径等仍需实测，不能保证所有来源都可捕获。

用户已确认：**开发零成本，第一版能用就行。**

- 不购买软件、模型、云服务、服务器或额外硬件；使用用户现有电脑。
- 不接入付费 API，不依赖免费试用额度，不要求 API Key。
- 使用免费且许可适用的依赖和本地模型。首次允许联网下载免费模型，准备完成后可离线运行。
- “零成本”指本项目不新增付费采购与服务支出；现有设备、电力、网络，以及执行开发所用平台的既有费用不属于软件能保证免除的范围。
- 优先级：跑通并可用 → 稳定 → 降低延迟 → 美化与扩展。

## 2. 目标用户与场景

面向需要理解英文视频的中文用户，优先支持日常视频、AI / ComfyUI / 编程教程。来源包括不同视频网站、在线课程和本地播放器。

默认捕获系统输出声音，不采集麦克风。多个软件同时出声可能被混在一起，使用时尽量只播放一个音源。

基本操作：启动工具 → 播放视频 → 点击开始 → 看中文字幕 → 点击停止。

## 3. 核心流程

```text
系统音频捕获（WASAPI Loopback）
  → 音频转换与短片段缓存
  → 分段 / VAD
  → faster-whisper 本地英文识别
  → 免费本地英译中模型
  → PySide6 悬浮中文字幕
```

采用连续短片段处理即可，不要求真正流式识别。先以约 1～3 秒分段为调优起点，结合语音停顿与最长片段限制。VAD 采用现成免费实现，不开发自有算法；不能将其当作可靠的音乐过滤器。

后台执行捕获、识别和翻译，避免卡住界面。队列必须有上限，防止字幕越来越落后；过载时提示调整模型或按明确策略丢弃过时片段。

## 4. 第一版必须实现

| 功能 | 最低要求 |
| --- | --- |
| 开始 / 停止 | 可反复操作；停止后释放捕获资源，不显示旧任务结果 |
| 系统音频 | 优先监听默认输出设备；设备不支持时给出明确提示 |
| 英文识别 | faster-whisper 本地运行，先使用适合现有电脑的小模型 |
| 中文翻译 | 免费本地英译中模型，无账号、无 API Key、无调用费用 |
| 悬浮字幕 | 简体中文、置顶、可拖动、合理换行，默认半透明黑底和清楚字号 |
| 基础状态 | 显示模型加载、运行、停止和错误原因 |
| 启动方式 | 提供双击启动入口与简短使用说明，无需每次输入命令 |

第一版只需要一个合适的识别模型和一个翻译模型，不必做模型选择界面。若默认设备捕获不可用，再增加最小必要的设备选择。

## 5. 非目标与延期功能

第一版不做：账号、云同步、付费服务、在线翻译、浏览器插件、网站解析、视频下载、麦克风采集、多人识别、实时配音、指定应用音频隔离、跨平台支持。

以下功能延期，不作为第一版验收阻塞项：双语切换、字号和透明度设置、鼠标穿透、位置记忆、术语编辑器、字幕导出、自动更新、复杂安装器和单文件 EXE。

不绕过受保护音频，不承诺零延迟或百分之百正确。

## 6. 技术选型建议

| 模块 | 建议 |
| --- | --- |
| 主语言 | Python |
| 系统音频 | 支持 WASAPI Loopback 的现成免费库；先验证真实捕获 |
| 音频处理 | NumPy 与必要的声道转换、重采样 |
| VAD | 现成可本地运行的免费实现 |
| 识别 | faster-whisper，优先小模型；CPU 可运行，有兼容 GPU 再加速 |
| 翻译 | 一个免费、许可适用、可离线部署的英译中模型，优先低资源占用 |
| 界面 | PySide6，一个简单控制窗与一个悬浮字幕窗 |
| 启动 | 第一版可提供双击启动脚本；环境安装写进首次准备说明 |
| 后续打包 | 功能稳定后再考虑 PyInstaller 应用目录或 EXE |

实施时核实依赖版本、Windows 兼容性、模型许可与免费获取方式。先验证捕获及翻译可行性，再做界面；不为未来功能提前搭框架，不引入数据库或服务器。

## 7. 延迟目标

第一版允许几秒延迟，先确保能持续显示可理解的中文字幕。

- 模型加载后，从短句结束到中文字幕出现，争取约 2～5 秒；这是调优目标，不是所有电脑的硬性承诺。
- 在现有硬件上测量实际延迟，记录所用模型和运行模式。
- 长句也要分段显示，不能无限等待句尾。
- 连续播放时延迟不得持续累积；硬件不足时优先缩小模型并提示，不要求购买硬件。
- 首次下载和模型加载时间单独说明。

第一版可用的判断：字幕持续出现、主要意思可理解、界面能操作、延迟有界。若达不到此条件，应继续调整，不能以“程序启动成功”代替验收。

## 8. 性能与硬件要求

优先用户现有 Windows 电脑，开发时确认系统版本、CPU、内存、GPU 和可用磁盘空间。不得假定用户有高性能显卡。

支持 CPU 路径；如果现有 NVIDIA GPU 与运行依赖兼容，可使用加速，但不要求购买显卡。模型选择以现有电脑能够承担为依据，不设未经验证的显存门槛。

记录模型磁盘占用与运行资源占用。至少连续运行 15 分钟，界面保持响应，不崩溃，不出现持续积压或明显失控的内存增长。

## 9. 界面需求

控制窗只保留开始、停止和状态提示，必要时提供输出设备选择。使用默认显示样式，不制作复杂设置页。

字幕默认在屏幕底部居中，始终置顶、可拖动；显示最新中文内容，长句合理换行。静音时不反复刷新旧字幕，可在超时后清空。

优先验证普通窗口和浏览器全屏。独占全屏、多显示器、特殊 DPI 等兼容性可后续完善，交付时列出实际限制。

## 10. 术语处理

第一版尽量保留 ComfyUI、VAE、节点名和代码标识符等内容，可使用少量固定术语映射，不要求术语管理界面。

重点检查 checkpoint、latent、sampler、VAE decoder 等教程词汇。不要用简单子串替换造成新误译；若处理方式尚不可靠，先保留模型结果并记录问题。术语优化不阻塞基本闭环。

## 11. 字幕保存

第一版不要求保存功能，默认不保存原始音频和长期字幕记录。

若基础流程完成后增加文本导出，只需 UTF-8 TXT，包含会话相对时间、原文和译文。无须数据库、SRT、视频时间轴对齐或笔记功能。保存失败不得导致程序崩溃。

## 12. 异常与兼容性

- 无声音：继续监听，不持续生成虚构字幕，提示检查播放与输出设备。
- 模型缺失：说明免费模型下载或本地加载步骤；下载失败可重试。
- 音频设备不可捕获或断开：明确提示，允许停止和重启。
- GPU 不可用或资源不足：允许使用 CPU 或更小模型。
- 识别或翻译失败：显示可理解的错误，不自动发送到在线服务。
- 混音、噪声和重叠人声：允许准确率下降，说明使用限制。
- 受保护音频、特殊输出、独占模式：记录不支持的场景，不绕过限制。

至少用两个不同网站和一个本地播放器检查音频捕获与中文字幕，证明工具不局限于 YouTube。优先测用户实际使用的输出设备，其他设备以后补充。

## 13. 隐私与成本

音频、识别和翻译全部在本机处理。模型准备后，断网仍可使用核心功能。

不上传音频或字幕，不做遥测，不接入云服务。仅首次安装依赖和下载免费模型需要联网，应说明来源与存储位置。

不把免费试用 API、限量免费云服务或需付费解锁的模型当作零成本方案。检查所用工具和模型许可是否适合预期使用及分发。

## 14. 开发阶段与验收

### 阶段一：本地最小流程

先完成系统音频 → 分段 / VAD → 英文识别 → 本地中文翻译。此阶段可以只输出文本，用于验证选型。

验收：真实视频播放时持续产生原文和译文；模型准备后断网可用；无需账号、密钥或付费服务。

### 阶段二：可用界面

接入开始 / 停止及 PySide6 悬浮中文字幕，提供双击启动入口。

验收：用户无需每次输入命令即可启动；能拖动字幕；开始 / 停止可反复操作；普通视频观看过程中界面不阻塞。

### 阶段三：基本验证与交付

测试两个网站、一个本地播放器，连续播放至少 15 分钟。用至少 10 条清晰英文样本人工检查日常语句和常用技术术语，逐条记录明显误译；至少 8 条主要意思可理解。

验收：字幕持续更新，主要意思可理解，延迟无持续累积，无崩溃；断网运行通过。记录硬件、模型、实际延迟和已知限制。若不能达到基本可用条件，继续缩小模型或调整流程，不以付费方案替代。

交付：源代码、依赖说明、双击启动入口、首次模型准备步骤、简短使用说明和测试结果。EXE 打包及延期功能不阻塞这一版交付。

## 15. 后续可扩展方向

基础版本稳定后，再考虑双语切换、外观调整、TXT / SRT 导出、术语词典、指定应用捕获、更多源语言、更低延迟和 EXE 打包。

在线服务、教程总结和复杂功能均不属于当前任务，未来只有用户明确要求才另行评估。

先跑通捕获、识别、翻译，再加简单界面。不要购买服务或硬件，不要接付费 API，不依赖免费试用额度，不提前开发延期功能。允许第一版使用默认样式、一个固定模型组合和双击启动脚本。以真实音频、离线运行和基本可用验证结果交付。
